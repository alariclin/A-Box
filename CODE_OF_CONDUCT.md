# Code of Conduct

## Our standards

- Be direct and factual. Criticise the code or the claim, never the
  person. Back claims with evidence: a log, a fixture, a one-line
  reproduction.
- No harassment, threats, slurs, or personal attacks — in issues, pull
  requests, reviews or any other project space.
- Do not post other people's private information (real IPs, domains,
  credentials, keys, personal data). Test reports must use redacted or
  documentation-range values.
- Respect the maintainer's decisions. A fix that is rejected after
  review stays rejected; reopen it only with new evidence.

## Scope

This applies to all project spaces: issues, pull requests, code
review, discussions and any chat or channel used for A-Box work.

## Enforcement

Violations can be reported by opening an issue at
https://github.com/alariclin/A-Box/issues (for conduct issues, state
clearly that the report is about conduct so it is handled privately
rather than as a technical thread). The maintainer reviews the report
and may warn, hide offending content, or block the account from the
repository. Decisions are final.
