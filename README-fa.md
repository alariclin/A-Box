مجموعه‌ابزار راه‌اندازی دروازه شبکه لینوکس با یک فرمان.

A-Box یک اسکریپت مستقل Bash برای راه‌اندازی و نگه‌داری دروازه‌های شبکه در لینوکس است. نسخه‌های سازگاری پیش‌فرض عبارت‌اند از Xray `v26.7.28` (نسخه پیش‌انتشار upstream که عمداً برای سازگاری نگه داشته شده)، sing-box `v1.14.3` و Hysteria `app/v2.13.0`؛ انتخاب آخرین نسخه پایدار نباید هسته جدیدتر نصب‌شده را بی‌صدا به نسخه پایین‌تر برگرداند.

این ابزار از Xray-core، sing-box، سرور رسمی Hysteria 2، VLESS Vision REALITY، VLESS XHTTP REALITY، Shadowsocks-2022، خروجی پیکربندی کلاینت، آزمون محلی نامزدهای SNI، پشتیبان‌گیری و بازیابی، مدیریت دیوار آتش، عیب‌یابی، محدودیت ترافیک، بررسی سلامت و به‌روزرسانی هسته‌ها پشتیبانی می‌کند.

> فقط در محیط‌های قانونی، مجاز و منطبق با مقررات از این پروژه استفاده کنید. مسئولیت تمام پیامدهای حقوقی، عملیاتی و امنیتی بر عهده کاربر است.

## رعایت قوانین و سلب مسئولیت

این پروژه برای آزمایش معماری شبکه، پژوهش امنیت سایبری، خودکارسازی مدیریت سیستم و حفاظت قانونی از حریم خصوصی در محیط‌های کاملاً مجاز در نظر گرفته شده است. از آن برای حمله غیرقانونی، دسترسی غیرمجاز، دور زدن ممیزی، سوءاستفاده از شبکه، اختلال در زیرساخت یا هر فعالیت غیرقانونی دیگری استفاده نکنید. فقط روی سرورها، شبکه‌ها و سیستم‌هایی از آن استفاده کنید که مالک یا مدیر آن‌ها هستید یا برای کار با آن‌ها مجوز صریح دارید.

این پروژه «همان‌گونه که هست» و بدون ضمانت ارائه می‌شود. پیش از اجرا، اسکریپت و تغییرات احتمالی آن در سیستم را بررسی کنید و پیش از نگه‌داری یا ارتقا، نسخه پشتیبان قابل‌بازیابی تهیه کنید.

## شروع سریع امن

### منبع رسمی GitHub

```bash
curl -fsSL https://raw.githubusercontent.com/alariclin/A-Box/a7cb193e6539cee6478648e766f5ce415ccd5d41/install.sh -o A-Box.sh
bash -n A-Box.sh && sha256sum A-Box.sh && less A-Box.sh
# پس از بررسی اسکریپت دریافت‌شده، جداگانه اجرا کنید:
sudo bash A-Box.sh
```

### آینه جایگزین شخص ثالث

```bash
curl -fsSL https://mirror.ghproxy.com/https://raw.githubusercontent.com/alariclin/A-Box/a7cb193e6539cee6478648e766f5ce415ccd5d41/install.sh -o A-Box.sh
bash -n A-Box.sh && sha256sum A-Box.sh && less A-Box.sh
# پس از بررسی اسکریپت دریافت‌شده، جداگانه اجرا کنید:
sudo bash A-Box.sh
```

هر دو فرمان نصب‌کننده را به commit تغییرناپذیر `a7cb193e6539cee6478648e766f5ce415ccd5d41` متصل می‌کنند؛ نشانی proxy همچنان سرویس انتقال شخص ثالث است، نه نقطه پایانی رسمی A-Box. بررسی نحو و SHA-256 به‌تنهایی هویت ناشر را ثابت نمی‌کند؛ فایل را پیش از اجرا بازبینی و برای production، commit و checksum را از کانالی مستقل و مورداعتماد تأیید کنید. در Alpine تازه، پیش از اجرا `apk add --no-cache bash curl` را اجرا کنید. پس از نصب `sb` را وارد کنید.

## قابلیت‌های اصلی

- **راه‌اندازی پروتکل‌ها:** Xray VLESS Vision REALITY، Xray VLESS XHTTP REALITY، Xray Shadowsocks-2022، سرور رسمی Hysteria 2 و گزینه‌های sing-box برای Vision، Shadowsocks-2022 و Hysteria 2.
- **پیکربندی‌های ترکیبی:** بسته Xray + Hysteria 2 و بسته sing-box Vision + Hysteria 2 + Shadowsocks-2022. بسته sing-box عمداً شامل XHTTP نیست.
- **خروجی تنظیمات کلاینت:** پیوند/URI، کد QR، فایل YAML برای Clash/Mihomo، قالب خروجی sing-box و JSON مربوط به XHTTP برای v2rayN/v2rayNG.
- **عملیات و عیب‌یابی:** سنجش سیستم و دانلود، کیفیت IP و مسیر، BBR/FQ با امکان بازگردانی، ترجیح IP، آزمون DNS و DoT/DoH در backend پشتیبانی‌شده، انتخاب شماره‌ای منطقه زمانی، Locale/NTP، نصب و پشتیبان‌گیری Wallos، Fail2Ban/logrotate، محدودیت ترافیک، پشتیبان‌گیری و عیب‌یابی.
- **عملیات:** Reality با یک کلیک، حالت سریع/سخت‌گیرانه (`ABOX_FAST`)، نسخه‌های ثابت هسته با قابلیت بازگشت، افزودن/لغو چند UUID در سمت سرور، خروجی URI/Base64/Clash و بررسی واقعی دسترس‌پذیری منابع دانلود.
- **آینه‌های هسته:** Release ثابت [`A-Box Core Binary Mirrors`](https://github.com/alariclin/A-Box/releases/tag/core-binaries) هم دارایی‌های نسخه سازگار ثابت و هم نسخه‌های شماره‌گذاری‌شده از آخرین انتشار پایدار رسمی Xray، sing-box و Hysteria را نگه می‌دارد. گردش‌کار هفتگی draft/prerelease را رد می‌کند، SHA-256 رسمی و معماری دارایی‌ها را بررسی می‌کند و نسخه اجرایی را فقط برای باینری‌هایی می‌سنجد که روی runner قابل اجرا هستند؛ نسخه‌های قدیمی برای بازگشت حفظ می‌شوند. نصب‌کننده پیش از نصب، نسخه واقعی باینری را در سیستم مقصد نیز بررسی می‌کند. هنگام شکست upstream، ابتدا آینه همان نسخه و سپس نسخه سازگار ثابت امتحان می‌شود. `SHA256SUMS` مانیفست یکپارچگی در همان Release است، نه امضای مستقل؛ جزئیات در [`mirrors/README.md`](mirrors/README.md).
- **گردش کار نامزدهای SNI:** آزمون محلی کامل و سبک، مشاهده نتایج ذخیره‌شده، اعتبارسنجی ورودی، محدودیت اندازه فایل و تعداد سطرها، حذف موارد تکراری و استفاده از حافظه نهان محلی معتبر یا فایل داده مجاور در صورت وجود.
- **نگه‌داری:** به‌روزرسانی کنترل‌شده اسکریپت با نمایش SHA-256 و تأیید صریح، به‌روزرسانی داده‌های Geo برای Xray و ارتقای مستقل هسته بدون بازنشانی پارامترهای نود.
- **کنترل‌های ایمنی:** بررسی پیش از راه‌اندازی، تغییر کنترل‌شده وضعیت سرویس‌ها، مدیریت قوانین دیوار آتش و مسیرهای بازگشت برای عملیات پشتیبانی‌شده.

فهرست بذر نامزدها در مخزن: [`data/sni-candidates.txt`](data/sni-candidates.txt). موارد فهرست SNI صرفاً نامزد هستند. وجود یک نام میزبان در فهرست **تضمین نمی‌کند که در حال حاضر از یک VPS مشخص قابل دسترسی باشد یا شرایط TLS/ALPN/SAN موردنیاز برای پیکربندی REALITY را داشته باشد**. پیش از استفاده، نامزدها را از شبکه مقصد بررسی کنید. اگر فهرست معتبر یا نسخه پشتیبان معتبر در دسترس نباشد، فرایند SNI متوقف می‌شود و از داده بررسی‌نشده استفاده نمی‌کند.

### جعبه ابزار

تمام قابلیت‌های قبلی حفظ شده‌اند: آزمون سیستم و سرعت دانلود، ارزیابی کیفیت IP، بررسی کامل و سبک SNI، مدیریت WARP، ایجاد Swap دو گیگابایتی، پشتیبان‌گیری/بازیابی، گزارش عیب‌یابی بدون اسرار، پیش‌آزمایی و خروجی اشتراک. زیرمنوهای BBR/FQ (اعمال و بازگردانی)، تنظیمات میزبان (ترجیح IP، DNS عادی، DoT فقط در صورت پشتیبانی backend، سنجش DNS، DoH در محیط پشتیبانی‌شده، منطقه زمانی/locale/NTP و ترجیح منبع دانلود) و نصب، ارتقا، وضعیت و پشتیبان‌گیری Wallos نیز افزوده شده‌اند. BBR فقط با انتخاب دستی اجرا می‌شود و پس از نصب پروتکل به‌صورت خودکار فعال نمی‌شود.

گزینه‌های آزمون ابتدا به آینه تأییدشده A-Box (Release `test-tools-mirror`) متصل می‌شوند و تنها در صورت تطبیق SHA-256 با `SHA256SUMS` اجرا می‌شوند. اگر آینه در دسترس نباشد یا checksum نامعتبر باشد، تنها در صورت تنظیم `ABOX_ALLOW_UNVERIFIED_UPSTREAM=1` به اسکریپت upstream بازمی‌گردند (تأییدنشده، بدون SHA pin)؛ در غیر این صورت اسکریپتی اجرا نمی‌شود.

Wallos برنامه‌ای اختیاری برای مدیریت اشتراک‌هاست. نصب‌کننده نسخه پایدار و تصویر Docker متناظر را دریافت می‌کند و هنگام شکست منبع اصلی از Release ثابت `wallos-mirror` استفاده می‌کند. فایل پشتیبان ابتدا موقتاً ساخته و اعتبارسنجی می‌شود، سپس به‌صورت اتمی منتشر می‌شود. Wallos به‌طور پیش‌فرض فقط روی `127.0.0.1` در دسترس است؛ برای دسترسی راه دور از HTTPS reverse proxy یا SSH tunnel استفاده کنید. انتشار HTTP بدون TLS روی همه رابط‌های IPv4 فقط با تنظیم صریح `WALLOS_BIND_ADDRESS=0.0.0.0` و تأیید مجدد ممکن است. تازه‌سازی آینه اسکریپت‌های شخص ثالث نیازمند اجرای دستی workflow و تأیید است.

BBR/FQ بدون تأیید اعمال نمی‌شود. انتخاب DNS بر اساس درخواست‌های واقعی از همان VPS انجام می‌شود و فقط نتیجه همان بازه آزمایش را نشان می‌دهد، نه رتبه‌بندی جهانی. DoT فقط در backend پشتیبانی‌شده فعال می‌شود و نام احراز هویت TLS بالادست را می‌خواهد تا systemd-resolved گواهی سرور DNS را بررسی کند (برای مثال `1.1.1.1#cloudflare-dns.com` یا `8.8.8.8#dns.google`)؛ DoH با `dnscrypt-proxy` و فقط در ترکیب پشتیبانی‌شده با systemd-resolved ارائه می‌شود. تنظیم DNS و منطقه زمانی مسیر بازگردانی دارند.

انتخاب زبان، منوی اصلی، منوهای نگهداری و ابزارهای جدید را پوشش می‌دهد؛ برخی راهنماهای قدیمی پروتکل و پیام‌های خطا ممکن است همچنان شامل متن چینی یا انگلیسی باشند.

## استفاده از خط فرمان

نام فایل در مخزن `install.sh` است. نمونه‌های curl بالا آن را به‌صورت `A-Box.sh` ذخیره می‌کنند؛ اگر محتوا همین اسکریپت باشد هر دو نام قابل قبول است.

فرمان‌ها را از پوشه‌ای اجرا کنید که اسکریپت دانلودشده در آن قرار دارد:

| فرمان | کاربرد |
|---|---|
| `sudo bash A-Box.sh --help` | نمایش راهنمای خط فرمان |
| `sudo bash A-Box.sh --lang zh` / `--lang zh-tw` / `--lang en` / `--lang ja` / `--lang ru` / `--lang fa` | انتخاب زبان رابط و باز کردن منو |
| `sudo bash A-Box.sh --self-test` | اجرای آزمون‌های داخلی رگرسیون |
| `sudo bash A-Box.sh --preflight` یا `--dry-run` | بررسی پیش از اجرا، بدون راه‌اندازی نود جدید |
| `sudo bash A-Box.sh --status` | نمایش پیکربندی و وضعیت سرویس‌های مدیریت‌شده |
| `sudo bash A-Box.sh --start` / `--stop` | شروع/توقف سرویس‌های مدیریت‌شده |
| `sudo bash A-Box.sh --version` | نمایش فراداده ساخت اسکریپت |
| `sudo bash A-Box.sh --export-backup-key /secure/path/A-Box-recovery.key` | خروجی گرفتن از کلید بازیابی در مسیر محافظت‌شده |
| `sudo bash A-Box.sh --convert-legacy-backup OLD.tar.gz [OUTPUT_DIR]` | تبدیل نسخه پشتیبان قدیمی به قالب manifest v3 |

کلید بازیابی و نسخه‌های پشتیبان را در محل امن نگه دارید. موفقیت `--self-test` جایگزین بررسی پیش از اجرا روی سرور مقصد، نصب واقعی یا آزمون سازگاری کلاینت‌ها نیست.

## نیازمندی‌های سیستم

اسکریپت مسیرهای سازگاری برای محیط‌های زیر دارد؛ عملکرد واقعی به نسخه سیستم‌عامل، سامانه راه‌اندازی، معماری، وابستگی‌ها، شبکه ارائه‌دهنده VPS و در دسترس بودن دانلودهای بیرونی بستگی دارد.

| مورد | نیازمندی |
|---|---|
| خانواده سیستم‌عامل | Debian 10+، Ubuntu 20.04+، CentOS/RHEL/Rocky/AlmaLinux 8+ یا Alpine Linux |
| سامانه راه‌اندازی | systemd یا OpenRC |
| معماری پردازنده | amd64/x86_64 یا arm64/aarch64 |
| سطح دسترسی | root یا sudo |
| شبکه | دسترسی به مخازن بسته‌های سیستم و نشانی‌های ضروری upstream/GitHub Releases |
| زبان رابط اسکریپت | چینی، انگلیسی، روسی و فارسی؛ برای پیام‌های قدیمی به توضیح بالا توجه کنید |

منوی زبان اسکریپت چینی، انگلیسی، روسی و فارسی را ارائه می‌کند. منوی اصلی و منوهای عملیاتی به‌روزشده ترجمه شده‌اند؛ برخی پیام‌های قدیمی در راهنمای نصب پروتکل‌ها همچنان دوزبانه‌اند و ممکن است متن چینی/انگلیسی داشته باشند.

## فهرست بررسی برای محیط عملیاتی

1. اسکریپت را بررسی کنید و از منبع معتبر با نسخه ثابت استفاده کنید؛ به آینه‌های شخص ثالث کورکورانه اعتماد نکنید.
2. پیش از راه‌اندازی، `--self-test` و `--preflight` را روی VPS مقصد اجرا کنید.
3. قوانین دیوار آتش/گروه امنیتی ارائه‌دهنده و سازگاری پروتکل، پورت‌ها و کلاینت انتخاب‌شده را بررسی کنید.
4. کلید بازیابی را جداگانه نگه دارید و پیش از نگه‌داری مخرب، نسخه پشتیبان معتبر تهیه و بررسی کنید.
5. DNS، TLS، ALPN، SNI، دسترس‌پذیری و رفتار کلاینت را از شبکه‌های واقعی کاربران بررسی کنید. موفقیت CI به‌تنهایی سازگاری با همه ارائه‌دهندگان VPS، سیستم‌عامل‌ها یا کلاینت‌ها را ثابت نمی‌کند.
